 Special case of Table with element_to_mobject set to Integer .
Will round if there are decimal entries in the table. 

 Parameters : 

 table ( Iterable [ Iterable [ float | str ] ] ) – A non-empty, finite iterable of equally sized iterables. The content
has to be valid input for Integer . 
 element_to_mobject ( Callable [ [ float | str ] , VMobject ] | type [ VMobject ] ) – The Mobject class applied to the table entries. Set as Integer . 
 kwargs ( Any ) – Additional arguments to be passed to Table .
