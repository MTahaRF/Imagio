 Special case of Table with element_to_mobject set to DecimalNumber .
By default, num_decimal_places is set to 1.
Will round/truncate the decimal places based on the provided element_to_mobject_config . 

 Parameters : 

 table ( Iterable [ Iterable [ float | str ] ] ) – A non-empty, finite iterable of equally sized iterables. The content
has to be valid input for DecimalNumber . 
 element_to_mobject ( Callable [ [ float | str ] , VMobject ] | type [ VMobject ] ) – The Mobject class applied to the table entries. Set as DecimalNumber . 
 element_to_mobject_config ( dict ) – Element to mobject config, here set as {“num_decimal_places”: 1}. 
 kwargs ( Any ) – Additional arguments to be passed to Table .
